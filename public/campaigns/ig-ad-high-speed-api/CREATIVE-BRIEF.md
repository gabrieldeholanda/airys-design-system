# Creative Brief: High-Speed API Instagram Ad

## Target Audience & Objective
**Audience**: Developers, CTOs, and technical founders looking to scale their AI integration or chat operations with minimal latency.
**Objective**: Drive awareness and clicks for the new AirysChat high-speed API feature. Position Airys as the most reliable, lightning-fast solution for enterprise AI operations.
**Platform**: Instagram (1080x1080 static image).

## Layout Strategy & Visual Hierarchy
- **Vibe**: Tech-forward, premium, dark-mode aesthetic. Glassmorphism elements. High-tech "speed" indicators (like a subtle neon grid or glowing data streams).
- **Background**: Deep dark surface `hsl(var(--background))` with subtle primary color gradients `hsl(var(--primary-500))` indicating energy and speed.
- **Main Visual Hook**: A glowing, sleek code block or API terminal window hovering in 3D, emitting a subtle neon glow, symbolizing raw data throughput.
- **Typography & Placement**: 
  - Centered or top-aligned bold heading using a modern sans-serif.
  - Minimalistic bottom-centered CTA.
  - Airys logo subtly placed in the top-left or bottom-right corner.

## Copywriting Instructions
- Keep it punchy and developer-focused. 
- Use active, commanding verbs.
- Highlight "speed" and "API".
- Keep text length minimal for Instagram readability.

## Visual Design Instructions
- **Colors**: Deep dark grays/blacks for the background. Vibrant neon accent (Primary 500) for the focal point and data streams.
- **Composition**: Symmetrical, centered focus on the API representation.
- **Mood**: Serious, hyper-efficient, "humanized AI" meets raw computing power.
