# Research Summary: Airys Design System

## Key Findings

**Stack:** Figma for design, Tokens Studio for JSON export, Storybook for component docs, React/TS + CSS Variables for code.
**Table Stakes:** Dark-mode focused color palette, modern typography, base UI components (buttons, inputs), and clear brand guidelines.
**Watch Out For:** Contrast issues in dark mode and hardcoding hex values instead of using semantic tokens.
