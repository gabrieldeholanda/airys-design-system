# Features Research: Airys Design System

## Core Brand Identity (Table Stakes)
- Logo files (SVG, PNG) in light/dark variants
- Defined color palette with semantic mapping (primary, background, surface, text)
- Typography scale (headings, body, captions)

## UI Components (Table Stakes)
- Buttons (primary, secondary, outline, ghost)
- Form inputs (text, select, radio, checkbox)
- Feedback (modals, toasts, tooltips)
- Layout primitives (cards, containers)

## Marketing Assets (Differentiators)
- Pitch deck templates (aligned with the dark/tech aesthetic)
- Custom illustrations matching the "humanized AI" theme
- Landing page hero sections and feature grids

## Anti-Features
- Complex 3D components (out of scope for v1)
- Native mobile widgets (sticking to web-first responsive design)
