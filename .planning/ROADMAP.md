# Roadmap: Airys Design System

**Goal:** Establish a comprehensive design system for all Airys web products, starting with core brand identity and moving towards reusable UI components and marketing assets.

## Phases

### Phase 1: Core Brand Identity
**Goal:** Define the foundational brand assets including logo variations, color palette optimized for dark mode, and typography scale.
**Mode:** mvp
**Requirements:** BRND-01, BRND-02, BRND-03
**UI hint:** yes
**Success Criteria:**
1. Color palette is exported as semantic CSS variables.
2. Typography scale is defined and documented.
3. Airys logo assets are readily available in light and dark variants.

### Phase 2: Core UI Components
**Goal:** Implement the base UI components relying on Phase 1 design tokens to establish a consistent look and feel across forms and interactions.
**Mode:** mvp
**Requirements:** COMP-01, COMP-02, COMP-03, COMP-04
**UI hint:** yes
**Success Criteria:**
1. Button component handles 4 variants (primary, secondary, outline, ghost).
2. Form inputs render consistently in dark mode.
3. Modal and Card components correctly utilize surface and background colors.

### Phase 3: Marketing & Presentation Assets
**Goal:** Translate the brand identity and components into high-value marketing assets (decks and landing pages).
**Mode:** mvp
**Requirements:** MRKT-01, MRKT-02, MRKT-03
**UI hint:** yes
**Success Criteria:**
1. A standard pitch deck template is created in the brand aesthetic.
2. Core illustrations representing "humanized AI" are completed.
3. The landing page hero section is designed using the Phase 2 components.
